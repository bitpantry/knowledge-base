# Lead

Stable model ID: `lead`. Owned by Pipeline; only `account.py` writes its extension records. A specific possible follow-up or need in a known account can support a lead. A broad mention or ambiguous membership should not become a lead. This extension doesn't create an opportunity in an external CRM.

Record ID starts with `lead-`. Store the explicit account key, title, optional concise description, existing same-account person and interaction IDs when known, and core references when available. Status is current only: `open`, `qualifying`, or `closed`. A lead may be reopened explicitly; the initial version does not keep a separate lead status history. Source evidence remains unchanged.
