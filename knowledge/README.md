# Knowledge records

[Concepts, evidence, and confirmations](../core/CONCEPTS.md) are indexed here when filed through the CLI. Empty categories are created on first use. This area is for audience-approved metadata and concise sourced claims, not raw originals or examples.

[Extension interpretations](../core/RECONCILE.md) can link existing records to independent extension models. They are optional local data, not changes to the original notes.
